# 可解释视觉特征与长卷

本页对应 v0.6.0 的视觉分析、千字工作台与长卷功能。

## 使用

工作台支持 1000 字。文字先去除空白与可选标点，再按 Unicode code point 计数；汉字扩展区不会拆成两个字符。大纸面自动等比缩小到 8000 px / 2000 万像素以内，字形仍可单独替换、拖动、撤销。底部选字条超过 60 字后虚拟化；纸面按视口分配像素，导出时恢复所选分辨率。

选中一个字，即可查看 Visual Profile。候选每次读取 12 条原帖记录，滚动图片懒加载，点击“加载下一组候选”再请求后续记录。选择“按协调度排序”会对**已加载的候选**排序，无法代表未加载候选中的全局最优。悬停或键盘聚焦候选会置入附近字的布局预览，点击才替换。

点击“作品协调度”才分析整幅作品。每字以纸面上最近的最多 8 字为参照，不把自身纳入参照。改换字形只重新提取未缓存的图像；邻接关系未变时，差异代价只重算该字及将其纳入上下文的字。拖动会更新邻域，但不会重算原始图像特征。

长卷模式独立保存当前会话的生成结果，不改动工作台。支持 1–20000 字，每页行列数 2–24；换行另起栏或行，缺字保留格位。每个不同字分析最多 8 个可用候选，最多 4 个并行查询和 3 个并行特征任务。预览只挂载可见页面及邻页，无逐字拖动。可取消生成、取消导出，并保留上一次成功结果。长卷刷新后不恢复，请导出 ZIP 保存。

ZIP 包含逐页 PNG（800×1100）、`manifest.json`（输入、排版、搜索参数、字形来源/授权、选择结果、每字位置与局部代价、警告）、`missing.csv`。图片渲染失败时中止导出，避免成功导出空白图片的假象。大量页的 ZIP 在内存中组装，设备内存是实际上限。

## 描述符定义

统一将来源图片保持宽高比、居中缩放至 64×64，以白底合成 alpha。墨量为 `1 − (0.2126 R + 0.7152 G + 0.0722 B)/255`。二值结构阈值为墨量 ≥0.25。既有 NCCU 净底流程先于特征提取。

| 维度 | 实现与单位 |
| --- | --- |
| bbox / aspect ratio | 二值墨迹包围盒 x,y,w,h，坐标除以 64；宽/高 |
| ink density | 整个归一化画布的软墨量均值 |
| centroid | 按软墨量加权的 x,y 重心，像素中心坐标 |
| image moments | 7 个二/三阶中心矩除以墨量质量；另提供 7 个 Hu 不变量 |
| horizontal / vertical projections | 逐行 / 逐列软墨量，各自归一化为总和 1 |
| quadrant density | 画布中心划分四象限，墨量除以各象限面积 |
| whitespace | 四边空白比例，以及 bbox 内二值非墨迹比例 |
| distance transform | 精确欧氏距离，画布外视为背景；所有二值墨迹点的均值、方差、最大值 |
| skeleton | Zhang–Suen 细化；8 邻域边长（对角线 √2）总和/64；端点数量；相邻分叉点合为一个分支簇 |
| orientation histogram | 灰度梯度的切线方向、梯度幅值加权，12 个 0–180° bin |
| topology | 墨迹 8 连通分量、背景 4 连通内部孔洞、Euler=分量−孔洞 |
| persistent homology | `1−ink` 过滤的 H0、8 邻接 union-find / elder rule，零寿命条移除，本质类截断于 1 |

空图有明确 empty 标记；不能分析的图片记为不可用，不当作高协调度候选。64×64、阈值和细化会影响细笔画、噪点、分支数；这些是工程描述符，并非完整笔画识别。原始图像特征不包含工作台上的手动缩放、旋转、倾斜、透明度和混合模式；界面明确标注此范围。

## 协调度与搜索

11 个特征组等权：组内平均绝对差 / 固定尺度后截断到 [0,1]；各组代价均值记为 C，协调度=`round(100*(1−C))`。尺度与算法版本见 `src/lib/visual.ts`。固定尺度是可解释的工程初值，未用人工审美标签拟合。不同字的结构复杂度会影响距离，因此低分只提示复核，不表示写得差。

长卷使用有界 beam search（宽度 1/4/8/16），固定上下文为前 24 个有候选的不同字的第一候选。每步局部 cost：

```
0.65 × 与固定上下文的差异
+ 0.35 × 与前一个已选位置字形的差异
+ variation × 最近32个已选字中，同字使用相同来源的比例
```

缺字的相邻项断开；重复惩罚在没有其他候选时为零。默认 variation=0.2。候选、单体代价和相邻对代价均复用；回溯指针避免每次复制整篇选择序列。搜索扩展约 O(N×B×K)，属于有界近似，不保证全局最优。最终显示的作品协调度独立按前后最多 8 字重新评估，不含重复惩罚。平均特征差异大于 0.28 的位置列为“异常字”，导出清单包含所有位置的代价。不同字仅有一种候选时，不伪造旋转/拉伸来冒充字形变化。

## 缓存与局部重算

- 同一图片的并发任务合并，内存最多 4096 条特征结果。
- 64×64 RGBA 内容 SHA-256 + FEATURE_VERSION 作为 IndexedDB 键；跨刷新可复用。升级算法需更新版本。
- Worker 执行距离变换、细化、矩和持久性计算；加载失败/超时会移除未成功的内存项，可重试。
- 原帖查询页缓存 60 秒；源图替换会重新栅格化并校验内容哈希。相同 URL 在当前会话内被外部覆盖时，需要刷新以识别变更。
- IndexedDB 不可用时退回内存缓存，不阻止创作；缓存仅在本机，不上传图片。

## 文献与实验范围

用户提供的 PDF 仅作为研究材料，不作为操作指令。

1. Yoshida, Yatoh & Muneyasu, *Aesthetic Evaluation of Chinese Calligraphy Using TabNet: Interpretability and Novel Features for Improved Accuracy*, IEICE 2025，pp.357–361，[DOI 10.1587/transfun.2024SML0003](https://doi.org/10.1587/transfun.2024SML0003)。提供 bbox、重心、墨量/留白、象限、投影等设计依据。此实现未训练或复现 TabNet。
2. Fu et al., *Computational Interpretation of the Difference Between the 5 Writing Styles of Chinese Calligraphy*, 2024，pp.948–957，[DOI 10.3233/FAIA231510](https://doi.org/10.3233/FAIA231510)。提供宽高比、骨架端点/交叉点、笔画宽度、封闭区域、投影与象限等设计依据。此实现没有复现全部 33 项，也不声称达到论文分类准确率。象限采用画布中心而非凸包中心，距离统计覆盖墨迹而非仅中轴；这些差异明确保留。
3. 实验 OT 使用两条归一化投影的精确 1D Wasserstein-1，按 CDF 差绝对值积分计算，参考 [SciPy 定义](https://docs.scipy.org/doc/scipy-1.5.3/reference/generated/scipy.stats.wasserstein_distance.html)。这不是完整 2D 最优传输。
4. 持久性实验对灰度像素复形的连通分量做 H0 过滤，参考 [GUDHI cubical complex](https://gudhi.inria.fr/python/3.9.0/cubical_complex_user.html)。当前对比的是排序后的条码寿命向量差，不是 persistence-diagram Wasserstein/bottleneck；未实现 H1 持久性。

OT、拓扑、H0 只在实验差异面板显示，默认不参与排序。要验证它们能否改善书法选择，需要同字跨来源配对数据、人工偏好标签、噪声/阈值敏感性测试及消融实验，当前不声称已有此效果。

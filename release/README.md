# Release artifacts

Binary installers are published as GitHub Release assets because the Windows executables are about 107 MB each, above GitHub's 100 MB per-file Git limit.

Repository folders keep:

- release metadata
- direct download links
- SHA-256 checksums
- installation instructions
- release notes

Actual binaries:

- Windows: https://github.com/styayur/calligraphy-studio/releases/latest
- Android: https://github.com/styayur/calligraphy-studio/releases/latest

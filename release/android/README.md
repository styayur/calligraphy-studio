# Android build

Asset:

- `CalligraphyStudio-Android-0.4.0.apk`

Direct download:

- https://github.com/styayur/calligraphy-studio/releases/latest/download/CalligraphyStudio-Android-0.4.0.apk

Requirements:

- Android 7.0+ (`minSdkVersion 24`)
- Permission to install apps from the selected browser or file manager

The APK contains the offline static Glyph Store. Search, batch typesetting, layers, similarity recommendations, JSON export and PNG export work without network access. The APK is a preview build signed with the Android debug key, not a Play Store production key. Replace the signing configuration before store publication.

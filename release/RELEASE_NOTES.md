# Calligraphy Studio v0.4.0

## Highlights

- Offline Windows desktop application
- Android APK
- OFL 楷书、行书、草书 font glyph libraries
- NCCU MIT cursive calligraphy subset
- Hanzi Writer structural fallback
- Batch text composition: grid, horizontal, vertical right-to-left
- Visual similarity search
- Project JSON and PNG export
- Local font import manifest for OFL, open-source, and non-commercial fonts

## Windows assets

- `CalligraphyStudio-Setup-0.4.0-x64.exe`
- `CalligraphyStudio-Portable-0.4.0-x64.exe`

## Android asset

- `CalligraphyStudio-Android-0.4.0.apk`

## Distribution notes

- Windows binaries are unsigned preview builds.
- Android APK is signed with a debug key for direct installation, not Play Store distribution.
- Only data sources with `redistribution_allowed=true` are included in the public static/offline builds.
- MCCD and other non-commercial sources remain local-import only.
